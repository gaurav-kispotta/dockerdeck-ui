/* PURPOSE */
DockerDeck visualizes Docker Compose files as interactive diagrams.
Perfect for DevOps engineers, developers, and system architects.
Transform YAML configurations into beautiful visual representations.

/* FEATURES */
- Docker Compose YAML visualization
- Interactive container diagrams  
- Service dependency mapping
- Network topology visualization
- Volume relationship analysis
- Real-time editing and preview
- Dark/light theme support
- Mobile responsive design
- AST debugging capabilities
- Redux state management
